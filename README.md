# Page de test GitHub Pages

Bienvenue sur cette page de test ! Elle contient quelques blocs de contenu de démonstration pour vérifier le rendu Markdown sur **GitHub Pages**.

## À propos

Ce projet est un petit terrain d’essais pour expérimenter le Markdown, la mise en page et la publication de contenu sur GitHub.

## Fonctionnalités de démonstration

- Un titre principal et des sections
- Des listes à puces et des listes numérotées
- Du texte **important**, *stylisé* ou `mis en valeur`
- Des tableaux, des liens et des blocs de code
- Un exemple de site simple prêt à être personnalisé

## Mini liste de tâches

1. Créer un dépôt GitHub.
2. Activer GitHub Pages dans les paramètres.
3. Choisir la branche principale comme source.
4. Tester le contenu de cette page.
5. Remplacer les exemples par mon propre texte.
